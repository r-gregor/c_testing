# [E2] string-view #
####################
c-string is a single pointer to memory address at the beginning of charcter array
string-view has two integers: 'pointer' at the addres at the beginning of string and 'length'
it is very easy to convert null-terminated string into string-view because we just ignore the
'\0' character without allocating any memory or destroying any data

sv2 = 'Hello, World'
---
if we want to chop off from right, we need to use special printf format string count:
printf("%.*s"), sv2.count, sv2.data);
expression because original printf does not respect our '.count'
expression is included inside 'sv_print()' function, or
we can factor out the printf format string count into macro definition, like:
	#define SV_fmt "%.*s"
	#define SV_args(sv2) (sv2)->count, (sv2)->data

so 'printf("|%.*s|", sv2.count, sv2.data);' becomes: 'printf("|" SV_fmt "|", SV_args(sv2));'
this works because you can combine several parts of string literal into single one:
printf("'First " "part" " and " "second " "part'") ==> 'First part and second part'
---
new functions 'sv_chop_(left/right)' to chop off single char:
sv2 = 'Hello, World'

after chopping off from right 2 times:
sv2 = 'Hello, Wor'

and after chopping off from left 2 times:
sv2 = 'llo, Wor'
---
new functions 'sv_chop_n_(left/right)' to accept number of characters to chop off
